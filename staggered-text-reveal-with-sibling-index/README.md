# Staggered Text Reveal with sibling-index()

A Pen created on CodePen.

Original URL: [https://codepen.io/SultanKhanCQ/pen/xbVjLKg](https://codepen.io/SultanKhanCQ/pen/xbVjLKg).

Type any sentence and watch each word animate in sequence. The delay for each word is calculated purely in CSS using sibling-index() - no inline styles, no JavaScript timing. Add or remove words and the timing just works. Chrome 138+ required.
